This repository contains my solutions for [Advent of Code 2025](https://adventofcode.com/2025)!

**I have fully solved all 12 days.**

It is a fork of a repository containing CRCS member solutions for AoC.

[View the club's leaderboard](https://bettercs.club)

## Repository Structure

> This repository has been modified from the parent to contain only my solutions.

Each day will have its own directory following the naming scheme `day-xx`. For example, the first day will have a folder called `day-01` and the twelfth day will have a folder called `day-12`.

My solutions for each day's part is within each folder.
